# FLM with Exponential Cutoff and Random Diffusivity

Codes used for trajectory generation and statistical analysis of
fractional Laplace motion with exponentially truncated correlations
and distributed diffusivities.
## 1. Common files

- `parameter.py`
  Defines simulation parameters.

- `files.py`
  Contains file-reading and file-handling utilities.

## 2. Trajectory generation

The following scripts are used to generate stochastic trajectories:

- `FBM_trajectory.py`
  Generates fractional Brownian motion trajectories.

- `FLM_trajectory.py`
  Generates fractional Langevin motion trajectories.

- `generate_diffusivity.py`
  Generates random diffusivities.

- `generate_flm_dd.py`
  Main script for generating FLM trajectories with distributed diffusivities.

- `subordinator.py`
  Functions related to subordinated stochastic processes.

- To run the code, first run `generate_diffusivity.py` to generate diffusivity data, and then run `generate_flm_dd.py` to get the ensemble of stochastic trajectories. there are some choice for you when you run the code, like what kind of distribution of diffusivity and what kind of cutoff you want. 

- The code is not written in parallel computing form. But it is highly suggested if you're accessible to a server.

## 3. Data analysis

The following scripts are used for statistical analysis:

Data analysis without analytical result comparison:

- `stat_msd.py`
  Calculates the mean squared displacement (MSD).

- `stat_ngp.py`
  Calculates the non-Gaussian parameter.

- `stat_kurtosis.py`
  Calculates the kurtosis.

- `stat_pdf.py`
  Calculates probability density functions.

Data Analysis with analytical result comparison (the figures in the paper were generated by the following code):
- `stat_ngp_com.py`
  Additional NGP analysis.

- `compare_msd.py`
  Compares numerical and theoretical MSD results.

- `compare_kurtosis_gammaD.py`
  Compares kurtosis for different diffusivity distributions.

- `theory_pdf.py`
  Calculates theoretical probability density functions.

Parallel computing for non-gaussian parameter (not necessary):
- `stat_ngp_para.py`
  Parallel implementation of the NGP calculation.
